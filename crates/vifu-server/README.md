# vifu-server

HTTP, WebSocket, SQLite, PostgreSQL, relay, and trace implementation used by the
[`vifu`](https://crates.io/crates/vifu) application.

Install `vifu` to run the standard application. This lower-level crate is
available for custom server deployments that need to compose the implementation
directly.
