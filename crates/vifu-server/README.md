# vifu-server

HTTP, WebSocket, PostgreSQL, relay, and trace implementation used by the public
[`vifu`](https://crates.io/crates/vifu) crate.

Applications should normally depend on `vifu` and enable its `server` feature.
This package is published separately because crates.io must resolve every
dependency of the public facade.

[Repository](https://github.com/vifudotdev/vifu) |
[Documentation](https://docs.rs/vifu)
